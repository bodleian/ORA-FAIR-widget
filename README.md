# ORA and FAIR

The ORA FAIR project (https://ora.ox.ac.uk/FAIR) was created to explore ways to assess and report on the FAIRness of research data held in institutional repositories. 

This GitHub repository contains the code and documentation required to add the ORA Fair reporting widget to online records. 

## Resources
- In [FAIR CHAMPION OVERVIEW](FAIR_CHAMPION_OVERVIEW.md) we describe the ORA FAIR project's integration with the FAIR Champion service
- In [FAIR RESULT FORMAT](FAIR_RESULT_FORMAT.md) we describe the data structures used to save a FAIR assessment result for processing by the ORA FAIR widget.
